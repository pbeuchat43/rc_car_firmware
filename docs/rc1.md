# RC1 wire contract

USB CDC uses the field order and enum tokens in include/rc_car/wire.hpp. Lines are strict printable ASCII without spaces, at most 256 bytes including LF. Encode as @RC1,TYPE,fields...,CRC and LF. CRC is eight uppercase hex digits of CRC-32/ISO-HDLC through the comma before CRC. Test vector 123456789 produces CBF43926. Literal interoperability records are in tests/fixtures.

Use HELLO with a new 16-uppercase-hex challenge to start a session. The ID response echoes it and identifies a fresh 16-hex session, device and boot IDs, role RCCAR, board, build and profile. An identical live challenge is idempotent. A different challenge, USB loss, or transport service gap of at least 100 ms invalidates the previous session. A receive fragment aged 100 ms is discarded through LF.

Positive uint32 mutation sequences increase across all mutation types within the session, without wrap. Mutations echo a status tick that the Pico emitted in the live session. A future tick or age of 150 ms or more is stale. Reject frames without renewing any target or timer on error. uint64 time is monotonic milliseconds since boot. uint64 generation identifies actuator authority. Mode changes and either RC quality edge invalidate prior authority. HOLD may bypass the generation check with a valid session, sequence and tick. MODE and BENCH return RESULT. Status confirms staged output. DRIVE and PAN stream without individual replies.

The Pico sends STATUS every 40 ms. Mode, reason, retained cancellation generation and reason, both source selections, and staged PWM describe the same decision. RC validity and saturation masks use bit 0 for drive and bit 1 for steer. HOST, RC, and SUM select host, radio, and clipped addition, respectively. NONE represents neutral output or no choice. RC/RC is a MANUAL request. Pan PWM zero means the channel is disabled. Pan sequence zero can coexist with a held output from a prior session. Accepted drive sequence and selected drive sequence differ when no accepted command supplies an output.

Normalized fields are shortest signed decimal in -10000 through 10000. Other numbers are shortest unsigned decimal. Reject leading zeroes, plus signs, negative zero and integer overflow. No record is authenticated. The port belongs to a single authorized local operator or process.
